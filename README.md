# The Four Ages of AI

**From Machine Intelligence to Human Reinvention**

A long-form editorial website about the evolution of AI through four overlapping ages:

1. **Alchemy** — specialized learning architectures.
2. **Large Language Models** — Transformers, massively parallel computation, memory efficiency, scaling and reasoning.
3. **Agentic Computing** — distributed personal and cloud agents, software economics, security and human agency.
4. **Scientific Renaissance** — AI-assisted mathematics, physical discovery and future computing technologies.

## Hosting

The site is dependency-free: `index.html` contains all required HTML, CSS and JavaScript.

GitHub Actions workflow: `.github/workflows/pages.yml`. Enable **Settings → Pages → Build and deployment → GitHub Actions** once, then pushes to `main` redeploy the site automatically.
